Sebelum tukang mulai kerja, dia siapin dulu peralatannya: obeng, palu, meteran. Sebelum kamu mulai praktik ngoding beneran di course Web Dasar atau Python Dasar, ada baiknya kamu kenalan dulu sama "peralatan" standar yang dipakai hampir semua orang IT di dunia nyata.

## Kenapa Ini Penting?

Nama-nama alat ini bakal sering banget kamu dengar selama belajar di TCC — dan di dunia kerja IT beneran. Modul ini cuma kenalan singkat aja, biar kamu nggak asing pas ketemu istilahnya nanti.

## Text Editor: Tempat Nulis Kode

**Text editor** adalah aplikasi khusus buat menulis kode — beda dengan aplikasi menulis dokumen biasa (seperti Word), text editor dirancang khusus buat programmer: bisa mewarnai kode otomatis biar gampang dibaca, mendeteksi kesalahan penulisan, dan banyak fitur bantuan lainnya.

Salah satu text editor paling populer di dunia adalah **VS Code** (Visual Studio Code), buatan Microsoft dan gratis dipakai siapa saja. Nanti pas kamu belajar di course Web Dasar atau Python Dasar, sebagian praktik bisa langsung di browser (nggak perlu install apa-apa) — tapi mengenal VS Code tetap penting karena ini alat standar yang dipakai programmer di seluruh dunia.

## Terminal: Ngobrol Langsung dengan Komputer

**Terminal** (kadang disebut *command line*) adalah cara "ngobrol" dengan komputer pakai teks/perintah, bukan klik-klik ikon seperti biasa. Bayangkan kalau biasanya kamu menyuruh komputer lewat "bahasa isyarat" (klik, geser, tap), terminal itu kamu menyuruhnya langsung pakai "kalimat perintah" tertulis.

Contoh perintah sederhana di terminal: mengetik `python nama_file.py` buat menjalankan sebuah program Python. Programmer sering pakai terminal karena lebih cepat buat tugas-tugas tertentu dibanding klak-klik lewat tampilan biasa.

> 💡 **Tips:** Nggak perlu takut sama terminal — ini cuma cara lain buat "ngomong" ke komputer. Kamu bakal makin terbiasa seiring waktu.

## GitHub: Tempat Nyimpan & Berbagi Kode

**GitHub** adalah layanan online tempat programmer menyimpan, mengelola, dan berbagi kode proyek mereka — anggap seperti "Google Drive"-nya programmer, tapi dengan fitur khusus buat melacak setiap perubahan kode dan bekerja sama dalam tim.

Alat di balik GitHub namanya **Git** — sistem yang mencatat riwayat perubahan kode, supaya kalau ada kesalahan, kamu bisa "putar balik" ke versi sebelumnya. Bayangkan Git seperti tombol *undo* raksasa yang menyimpan seluruh riwayat perubahan proyekmu, bukan cuma langkah terakhir.

> ⚠️ **Perhatian:** Modul ini cuma kenalan nama & fungsi dasarnya aja. Pendalaman cara pakai Git dan GitHub beneran ada di course Web Dasar modul 8, nanti kamu praktik langsung di sana.

## Ringkasan

- **Text editor** (contoh: VS Code) adalah aplikasi khusus buat menulis kode.
- **Terminal** adalah cara memberi perintah ke komputer lewat teks, bukan klik-klik.
- **GitHub** (memakai alat **Git**) adalah tempat menyimpan, mengelola, dan berbagi kode, lengkap dengan riwayat perubahan.
