# Course: Kenal IT (Level 0)

Folder ini sengaja masih kosong dari sisi materi. Sensei tinggal membuat
folder modul di sini mengikuti format di `content/_templates/modul/`
(salin `lesson.md` + `tasks.json`, isi sesuai modul), lalu pastikan
slug foldernya cocok dengan yang terdaftar di `content/index.json`.

Contoh: modul "01-apa-itu-it" -> buat folder `content/level0/01-apa-itu-it/`
lalu isi `lesson.md` dan `tasks.json` di dalamnya.

Baca `docs/CONTENT-GUIDE.md` untuk panduan lengkap format konten.
