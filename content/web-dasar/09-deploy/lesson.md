Punya website keren dengan layout rapi dan warna elegan itu bagus. Tapi, website itu sejatinya hidup di internet. Kalau kodenya cuma ada di laptopmu (dan kamu akses dengan klik ganda file HTML-nya di browser), itu artinya belum selesai! Sekarang saatnya kita pamer karya ke teman sebangku atau keluarga dengan link website sungguhan (Deployment).

## Kenapa Ini Penting?

Setiap orang bisa mengklaim dirinya bisa membuat website. Tapi seorang programmer pemula secara resmi "lulus" menjadi web developer saat karyanya bisa diketik di HP orang lain di belahan bumi mana pun. Memahami *Hosting* dan *Domain* adalah pengetahuan dasar infrastruktur IT. 

## Domain dan Hosting (Alamat dan Rumah)

Untuk bisa membuat web kita online, kita butuh dua hal penting:
1. **Hosting:** Ini adalah "Tanah" atau "Rumah" tempat kamu menyewa komputer yang nyala 24 jam (server) untuk menaruh file HTML dan CSS-mu.
2. **Domain:** Ini adalah "Alamat Rumah" (contoh: `google.com`, `tcc15.my.id`) supaya orang tidak perlu repot mengetik angka-angka rumit untuk mengunjungimu.

## Panduan Praktis Online Gratis: GitHub Pages

Salah satu tempat hosting gratis terbaik di dunia untuk pemula adalah fitur rahasia milik GitHub: **GitHub Pages**. Langkahnya sangat simpel:

1. Buat **Repository** baru di akun GitHub kamu.
2. Namakan repo tersebut spesial, yaitu: `namamu.github.io` (misalnya: `udin.github.io`).
3. Upload (atau dorong dengan Git) file `index.html` milikmu ke dalam repo itu.
4. Pergi ke tab **Settings** ➔ cari menu **Pages**.
5. Pada bagian *Source/Branch*, pilih **main** atau **master**, lalu klik **Save**.
6. Tunggu 1–3 menit, lalu buka `https://namamu.github.io/` di browser HP-mu. Jreng! Websitemu sudah resmi mengudara di dunia nyata!

## Ada Cara Lain? (Vercel & Netlify)

Selain GitHub Pages, di industri modern banyak programmer menggunakan layanan super canggih seperti **Vercel** atau **Netlify**. Asyiknya layanan ini, kamu hanya butuh melakukan "Drag-and-Drop" (seret dan jatuhkan) foldermu dari laptop ke website mereka, dan dalam 10 detik websitemu akan online dan mendapat link URL gratis.

## Ringkasan
- Web yang cuma ada di folder laptopmu (Lokal) tidak bisa dilihat dunia. 
- Kamu butuh **Hosting** (tempat menyimpan) dan **Domain** (nama alamat).
- **GitHub Pages** adalah layanan hosting gratis andalan untuk halaman HTML sederhana.
- Cara paling mudah menaikkan web pemula saat ini adalah menggunakan *drag-and-drop* di Netlify/Vercel atau repo `username.github.io`.
