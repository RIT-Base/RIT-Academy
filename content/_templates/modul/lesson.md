Tulis 1 paragraf pembuka yang menjelaskan modul ini akan membahas apa, dan
kenapa penting buat anggota baru RIT.

## Sub-judul Pertama

Jelaskan konsepnya dengan bahasa yang santai dan gampang dimengerti pemula
yang baru belajar IT. Hindari istilah yang belum dijelaskan.

Kalau perlu contoh kode yang BISA DICOBA LANGSUNG oleh siswa, pakai fenced
code block dengan bahasa `html` atau `python` — platform otomatis mengubahnya
jadi editor interaktif (HTML Lab / Python Lab mini) tepat di dalam materi:

```html
<!-- Ini akan jadi HTML Lab interaktif di dalam materi -->
<h1>Halo, Dunia!</h1>
```

```python
# Ini akan jadi Python Lab interaktif di dalam materi
print("Halo, Dunia!")
```

## Sub-judul Kedua (opsional)

Lanjutkan penjelasan atau tambahkan blok kode interaktif lain kalau perlu.
Urutan blok kode `html`/`python` di file ini penting: task di `tasks.json`
bisa merujuk ke blok tertentu lewat `"block": <n>` (1-based, dihitung dari
blok kode pertama di file ini).

## Penutup

Tutup dengan ringkasan singkat, lalu arahkan siswa ke kartu checkpoint di
bawah materi untuk menyelesaikan task dan lanjut ke modul berikutnya.
