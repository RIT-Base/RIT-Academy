## Bikin Komputer Berbicara dengan `print()`

Fungsi paling dasar untuk menyuruh komputer mengeluarkan teks di layar adalah `print()`. Namanya memang print (cetak), tapi bukan cetak di printer kertas, ya! Cetak di sini maksudnya menampilkan ke layar monitor.

Coba tulis perintah ini:

```python
print("Halo, dunia!")
```

**Aturan Main:**
- Semua teks biasa (kalimat, huruf, kata) harus *diapit oleh tanda kutip*, bisa kutip dua `" "` atau kutip satu `' '`. Komputer melihat ini sebagai teks mati yang tidak perlu ia pahami maksudnya, cukup ditampilkan saja.
- Tanda kurung `()` adalah "keranjang" tempat kita menaruh apa yang mau di-*print*.
- Python itu sangat *case-sensitive* (membedakan huruf besar & kecil). Jadi `print` tidak sama dengan `Print` atau `PRINT`.

Coba mainkan editor mini ini. Ubah kata di dalamnya dan jalankan!

```python
# Coba ubah tulisan di bawah ini!
print("Salam kenal, saya anggota RIT!")
```

## Menulis Komentar yang Tidak Terlihat 

Kadang kamu mau meninggalkan pesan untuk dirimu sendiri (atau teman kerja) di dalam kode. Supaya Python tidak bingung menganggap pesanmu itu sebagai kode perintah, gunakan tanda pagar `#`.

```python
# Ini pesan rahasia, Python tidak akan menjalankannya
print("Hanya baris ini yang dijalankan")
# print("Baris ini dibisukan")
```

Menggunakan `#` sangat berguna untuk menyembunyikan baris kode sementara waktu (ini disebut nge-*comment* kode) atau untuk mencatat penjelasan.

## Ringkasan
- Python populer karena bersih dan mudah dibaca.
- Gunakan fungsi `print()` untuk mencetak teks di layar.
- Teks selalu diapit oleh tanda kutip `" "` atau `' '`.
- Karakter pagar `#` digunakan untuk menulis komentar yang akan diabaikan oleh eksekusi Python.
